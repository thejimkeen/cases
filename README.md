# Cases — 商业案例分析

这里存放我整理和撰写的各种商业案例研究。每个案例聚焦一个具体的商业问题、公司战略、产品决策或行业趋势，结合第一手资料与深度分析。

## 结构规划

- 每个案例一个独立 Markdown 文件
- 按照行业/主题分类管理（供应链、品牌营销、全球化、商业模式等）
- 每个案例包含标准化的 YAML frontmatter，便于检索、分类和AI知识库投喂
- 附带数据来源与分析框架说明

## 案例 Frontmatter 字段说明

每个案例都包含以下元数据字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `title` | 中文标题 | 嘉立创：为草根创客构建的产业生态 |
| `slug_en` | 英文索引slug | jlcpcb-grassroots-maker-industrial-ecosystem |
| `date` | 撰写/整理日期 | 2026-08-15 |
| `case_year` | 案例事件年份范围 | 2008-2026 |
| `status` | 状态：draft / published | draft |
| `company` | 涉及企业（中文） | 嘉立创（JLCPCB） |
| `brand_en` | 企业英文名 | JLCPCB |
| `industry` | 行业分类 | 电子制造/硬件创新 |
| `region` | 区域 | 中国/深圳/全球 |
| `case_type` | 案例类型 | 商业模式创新/产业生态构建 |
| `difficulty` | 难度：初级/中级/高级 | 高级 |
| `scenarios` | 适用场景（列表） | 教学案例, 产业生态分析 |
| `courses` | 配套课程（列表） | 商业模式创新, 战略管理 |
| `theories` | 适用理论（列表） | 长尾市场战略, 拼板经济学 |
| `tags` | 中文标签（列表） | 嘉立创, PCB打样, 产业生态 |
| `tags_en` | 英文标签（列表） | JLCPCB, PCB Prototyping |
| `description` | 一句话摘要 | 嘉立创通过"拼板经济学"、自建供应链、自研EDA... |

## 命名规则

文件名格式：`{品牌/主题}-{核心概念}.md`

- 企业品牌放前面，便于按企业索引
- 核心概念准确清晰，使用中文为主
- 避免"未命名"、"新建文件"等模糊命名
