# RPG 职业教育场景设计：物流新人的第一天

## 设计理念

将职业教育案例改造为 RPG（角色扮演游戏）形式，核心机制：

**像仙剑奇侠传一样：**
- 有人物、有对话、有剧情
- 决策影响后续走向
- 多种结局和评价
- 可重玩、可探索不同路径

**不同于娱乐游戏：**
- 冲突来自职业场景（不是打怪）
- 选择考验专业判断（不是道德选择）
- 奖励是能力提升（不是装备道具）

---

## 一、世界观设定

### 游戏背景

**公司：飞驰物流有限公司**
- 成立 8 年的中型物流企业
- 主要业务：城市间公路货运
- 团队：约 50 人（10 个调度、30 个司机、10 个后勤）
- 特点：业务量大、节奏快、要求响应快速

**你的身份：林晓**
- 刚入职一个月的物流助理
- 25 岁，物流管理专业本科
- 这是你的第一份正式工作
- 还在试用期，急于证明自己

**时间线：**
- 入职日期：2024 年 9 月 1 日
- 当前日期：2024 年 10 月 8 日（星期二）
- 工作时间：上午 8:45

## 二、主要 NPC 人设

### NPC 1：张雷（暴躁主管）

**基本信息：**
- 职位：调度主管
- 年龄：38 岁
- 工作年限：16 年物流行业经验
- 性格标签：#急性子 #要结果 #直来直去 #刀子嘴豆腐心

**人物特点：**
- 说话很冲，但都是为了把事情办好
- 不爱解释为什么，只说要什么
- 对新人严格，但暗地里会帮忙兜底
- 压力大时会骂人，但事后会给建议

**口头禅：**
- "别废话，能不能搞定？"
- "我不管你用什么办法！"
- "想清楚了再来跟我说！"
- "你自己看着办！"

**台词风格：**
```
差劲：
"你怎么还没搞定！"

好：
"你怎么还没搞定！我告诉你，这个客户上次因为晚了半小时，
 直接投诉到总经理那儿去了！三点之前必须到，听懂了吗？"
```

**成长系统：**
随着玩家完成任务，张雷的台词会变化：

| 玩家表现 | 张雷的态度 |
|---------|----------|
| 第 1-3 次任务 | 凶巴巴，质疑你的能力 |
| 第 4-6 次任务（做得好）| 开始信任，偶尔点头认可 |
| 第 7+ 次任务（优秀）| 会主动问你意见，开始培养你 |

**隐藏剧情：**
如果连续 5 次都做到 S 级评价，张雷会在下班时请你喝咖啡，讲他当年的故事，传授"老司机"的经验。

### NPC 2：小王（仓库管理员）

**基本信息：**
- 职位：仓库管理员
- 年龄：28 岁
- 性格标签：#话痨 #热心 #细节控 #有点啰嗦

**人物特点：**
- 什么都想告诉你，但不分主次
- 信息混在闲聊里，需要你主动提炼
- 是你的情报来源，知道很多内幕

**台词示例：**
```
"哎哟林晓来啦？今天要发货是吧？诶你看这批货，
 是昨天刚到的，那个供应商你知道吗，就上次来咱们仓库的那个老板，
 他每次发货都迟到，这次也是，说好早上八点到，结果十点才到。
 
 对了你问什么来着？哦对，这批货是服装，春装啦，
 一共 80 箱，每箱大概 15 公斤，你看这纸箱，质量不太好啊，
 千万别淋雨，一淋就完了。上次有批货就是淋了雨，
 客户直接拒收了，赔了好几万呢……"
```

**作用：**
训练学生从大量信息中提取关键点的能力。

**基本信息：**
- 职位：司机班长

**人物特点：**

## 三、核心玩法机制

### 3.1 决策系统

每个关键节点会出现选项：

```
[A] 直接行动型选项（快但风险高）
[B] 谨慎型选项（慢但稳妥）
[C] 寻求帮助/信息型选项（中庸，但消耗资源）
[D] 创新/冒险型选项（可能很好也可能很糟）
```

每个选项会显示：
- 选项内容
- 预计用时（如果有时间压力）
- 隐藏信息（某些选项需要解锁某些条件才能看到）

### 3.2 资源系统

**时间资源：**
- 每个任务有截止时间
- 某些行动会消耗时间
- 时间不够会导致负面结局

**信息资源：**
- 初始信息不完整
- 需要主动收集
- 某些信息需要"人脉"解锁

**信任度：**
- 与 NPC 的信任关系
- 影响能获得的帮助
- 做得好会提升，做得差会下降

### 3.3 评价系统

**实时反馈：**
每个决策后立即显示：
```
━━━━━━━━━━━━━━━━━━━━━━━
✅ 你收集了关键信息
💡 获得经验：信息收集 +5
⏱️  用时：5 分钟
━━━━━━━━━━━━━━━━━━━━━━━
```

**最终评价：**
```
━━━━━━━━━━━━━━━━━━━━━━━
任务完成！

【评级】A 级
【用时】4 小时 30 分钟
【成本】950 元（预算内）
【客户满意度】★★★★☆

【决策分析】
✅ 主动收集信息
✅ 风险评估到位
⚠️  成本控制可以更优化
❌ 突发情况响应稍慢

【张雷的评价】
"还行，下次记得提前看天气预报。"

【解锁成就】
🏆 谨慎决策者：完成任务时货物零损坏

【经验值】
信息收集：+10
风险评估：+8
沟通协调：+6
应急处理：+4

【下一个任务解锁】
→ 任务 2：多批次货物调度
━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.4 多周目机制

**初次游戏：**
- 有新手提示
- 某些选项会有"建议标签"

**二周目：**
- 提示减少
- 可以尝试不同路径
- 对比两次决策的差异

**速通模式：**
- 熟练后可以挑战"最短时间完成"
- 或"最低成本完成"
- 排行榜机制

## 四、游戏流程结构

### 章节设计

```
【序章】入职引导
├─ 认识张雷
├─ 熟悉系统界面
└─ 新手任务（简单送货）

【第一章】货车选择风波
├─ 场景 1：接到任务（本文档重点设计）
├─ 场景 2：收集信息
├─ 场景 3：做出决策
├─ 场景 4：突发状况
└─ 场景 5：复盘总结

【第二章】多批次调度危机
【第三章】客户投诉应对
【第四章】成本压力挑战
【第五章】突发事故处理
【终章】独立负责项目
```

每章结束后会有：
- 经验总结
- 能力成长树
- 张雷的评价变化

## 五、技术实现框架（建议）

### 5.1 前端结构

```
游戏主界面
├─ 对话框（显示 NPC 台词和旁白）
├─ 角色立绘（显示当前对话的 NPC）
├─ 选项按钮（玩家的决策选项）
├─ 状态栏（时间、成本、信息完整度）
└─ 背包/笔记（收集的信息和线索）
```

### 5.2 数据结构

```javascript
// 场景节点
{
  id: "scene_001",
  title: "接到任务",
  background: "office.jpg",
  npc: "zhang_lei",
  dialogue: "张雷看了你一眼，把一张订单甩到桌上...",
  options: [
    { id: "A", text: "立刻安排车辆", next: "scene_002a" },
    { id: "B", text: "先了解货物情况", next: "scene_002b" }
  ],
  conditions: {}, // 解锁条件
  effects: {} // 选择后的影响
}
```

### 5.3 后端功能

- 用户认证（学生账号）
- 进度保存
- 决策路径记录
- 数据统计（教师端查看）
- 排行榜

## 六、教学价值点

### 学习目标映射

| 游戏机制 | 对应职业能力 |
|---------|-------------|
| 信息收集阶段 | 工作前的尽职调查习惯 |
| 多因素权衡 | 决策分析能力 |
| 与暴躁主管对话 | 抗压和沟通能力 |
| 突发状况应对 | 应急处理和灵活性 |
| 成本计算 | 财务意识和效率思维 |
| 主动通知客户 | 服务意识和责任心 |

### 优于传统案例之处

| 传统案例 | RPG 形式 |
|---------|---------|
| 一次性阅读 10 页背景 | 信息逐步揭示，保持好奇心 |
| 抽象的"客户需求" | 具体的李经理在电话里发火 |
| 讨论"应该怎么做" | 真实体验"这样做的后果" |
| 成绩单上的分数 | 张雷的态度变化、成就解锁 |
| 一次考试 | 可以重玩，探索不同路径 |
