# 场景复用架构：内容与代码分离设计

## 核心理念

**一次开发，无限复用**

新增场景时：
- ✅ 只需编写 JSON 配置或 Markdown 剧本
- ❌ 不需要写任何代码
- ❌ 不需要修改前端组件
- ❌ 不需要修改后端逻辑

---

## 一、架构设计原则

### 1.1 内容驱动 vs 代码驱动

**错误的方式（代码驱动）：**
```javascript
// ❌ 每个场景都写死在代码里
if (sceneId === 'scene_001') {
  // 货车选择的逻辑
  if (choice === 'A') {
    nextScene = 'scene_002a';
  }
} else if (sceneId === 'scene_002') {
  // 多批次调度的逻辑
  // ... 又要写一遍类似的代码
}
```

**正确的方式（内容驱动）：**
```javascript
// ✅ 代码通用，内容是数据
const sceneData = await loadScene(sceneId); // 从数据库/文件加载
const engine = new SceneEngine(sceneData);   // 通用引擎
const result = engine.processChoice(choice); // 通用逻辑
```

### 1.2 分层架构

```
┌─────────────────────────────────────────────┐
│          内容层（Content Layer）             │
│   - 场景剧本（JSON/YAML/Markdown）            │
│   - NPC 对话库                               │
│   - 决策树定义                               │
│   - 评分规则配置                             │
└─────────────┬───────────────────────────────┘
              │ 通过标准格式传递
┌─────────────▼───────────────────────────────┐
│          引擎层（Engine Layer）              │
│   - 场景引擎（解释内容，驱动流程）            │
│   - 评分引擎（根据规则计算分数）              │
│   - 工具引擎（表单、计算器等）                │
└─────────────┬───────────────────────────────┘
              │ 提供标准接口
┌─────────────▼───────────────────────────────┐
│          UI层（Presentation Layer）          │
│   - 通用对话框组件                           │
│   - 通用选项组件                             │
│   - 通用表单渲染器                           │
│   - 通用评分展示                             │
└─────────────────────────────────────────────┘
```

**关键点：**
- 内容层：可以由**教师**编写，不需要程序员
- 引擎层：**程序员**开发一次，永久复用
- UI层：**设计师+程序员**开发一次，永久复用

## 三、通用引擎实现

### 3.1 场景引擎（核心）

```javascript
class UniversalSceneEngine {
  constructor(sceneDefinition) {
    this.scene = sceneDefinition;
    this.state = {
      currentNodeId: sceneDefinition.startNodeId,
      globalState: { ...sceneDefinition.globalState },
      history: [],
      decisions: [],
      startTime: Date.now()
    };
    
    // 注册内置函数
    this.registerBuiltInFunctions();
  }

  // 获取当前节点
  getCurrentNode() {
    return this.scene.nodes[this.state.currentNodeId];
  }

  // 处理任意类型节点
  async processNode(nodeId) {
    const node = this.scene.nodes[nodeId];
    
    // 根据节点类型调用对应处理器
    const handler = this.nodeHandlers[node.type];
    if (!handler) {
      throw new Error(`Unknown node type: ${node.type}`);
    }
    
    return await handler.call(this, node);
  }

  // 节点处理器映射
  nodeHandlers = {
    dialogue: async (node) => {
      // 应用状态变化
      if (node.effects?.stateChanges) {
        this.applyStateChanges(node.effects.stateChanges);
      }
      
      // 返回节点内容供前端渲染
      return {
        type: 'dialogue',
        content: this.interpolate(node.content),
        presentation: node.presentation,
        next: node.next
      };
    },

    choice: async (node) => {
      // 过滤可用选项（根据条件）
      const availableOptions = node.options.filter(opt => 
        this.evaluateCondition(opt.conditions)
      );
      
      return {
        type: 'choice',
        content: this.interpolate(node.content),
        options: availableOptions
      };
    },

    form: async (node) => {
      // 预处理表单（插值、条件字段）
      const processedForm = this.processForm(node.form);
      
      return {
        type: 'form',
        content: node.content,
        form: processedForm
      };
    },

    condition: async (node) => {
      // 自动评估条件并跳转
      for (const branch of node.conditions) {
        if (this.evaluateCondition(branch.condition)) {
          if (branch.narration) {
            // 显示旁白后跳转
            return {
              type: 'narration',
              content: { text: branch.narration },
              next: { type: 'auto', nodeId: branch.nextNodeId, delay: 2000 }
            };
          } else {
            // 直接跳转
            this.state.currentNodeId = branch.nextNodeId;
            return await this.processNode(branch.nextNodeId);
          }
        }
      }
      
      throw new Error('No condition matched in condition node');
    },

    calculator: async (node) => {
      return {
        type: 'calculator',
        content: node.content,
        calculator: node.calculator
      };
    },

    mini_game: async (node) => {
      return {
        type: 'mini_game',
        meta: node.meta,
        game: node.game
      };
    },

    end: async (node) => {
      // 场景结束，计算评分
      const score = await this.calculateScore();
      
      return {
        type: 'end',
        score,
        achievements: this.checkAchievements()
      };
    }
  };

  // 处理玩家选择
  async makeChoice(optionId) {
    const node = this.getCurrentNode();
    if (node.type !== 'choice') {
      throw new Error('Current node is not a choice node');
    }

    const option = node.options.find(opt => opt.id === optionId);
    if (!option) {
      throw new Error('Invalid option');
    }

    // 记录决策
    this.state.decisions.push({
      nodeId: this.state.currentNodeId,
      optionId,
      timestamp: Date.now(),
      timeSpent: Date.now() - this.state.lastNodeTime
    });

    // 应用效果
    if (option.effects?.stateChanges) {
      this.applyStateChanges(option.effects.stateChanges);
    }

    // 跳转
    this.state.history.push(this.state.currentNodeId);
    this.state.currentNodeId = option.next.nodeId;
    this.state.lastNodeTime = Date.now();

    // 保存进度
    await this.saveProgress();

    // 处理下一个节点
    return await this.processNode(this.state.currentNodeId);
  }

  // 提交表单
  async submitForm(formData) {
    const node = this.getCurrentNode();
    if (node.type !== 'form') {
      throw new Error('Current node is not a form node');
    }

    // 验证表单
    const validation = this.validateForm(node.form, formData);
    if (!validation.valid) {
      return { success: false, errors: validation.errors };
    }

    // 计算表单得分
    const formScore = await this.executeFunction(
      node.form.onSubmit.scoreLogic,
      { form: formData, gameState: this.state.globalState }
    );

    // 保存表单数据到状态
    this.state.globalState.formData = formData;
    this.state.globalState.formScore = formScore;

    // 跳转
    this.state.history.push(this.state.currentNodeId);
    this.state.currentNodeId = node.form.onSubmit.nextNodeId;

    await this.saveProgress();

    return {
      success: true,
      score: formScore,
      next: await this.processNode(this.state.currentNodeId)
    };
  }

  // 应用状态变化
  applyStateChanges(changes) {
    for (const [key, value] of Object.entries(changes)) {
      if (typeof value === 'string') {
        if (value.startsWith('+')) {
          // 增量
          const delta = this.evaluateExpression(value.substring(1));
          this.state.globalState[key] = (this.state.globalState[key] || 0) + delta;
        } else if (value.startsWith('-')) {
          // 减量
          const delta = this.evaluateExpression(value.substring(1));
          this.state.globalState[key] = (this.state.globalState[key] || 0) - delta;
        } else if (value.startsWith('${')) {
          // 表达式
          this.state.globalState[key] = this.evaluateExpression(value);
        } else {
          // 直接赋值
          this.state.globalState[key] = value;
        }
      } else {
        this.state.globalState[key] = value;
      }
    }
  }

  // 评估条件表达式
  evaluateCondition(condition) {
    if (!condition || condition === 'true') return true;
    if (condition === 'false') return false;
    
    // 插值替换
    const expr = this.interpolate({ text: condition }).text;
    
    // 安全执行（使用 Function 而不是 eval）
    try {
      const func = new Function('gameState', `return ${expr}`);
      return func(this.state.globalState);
    } catch (error) {
      console.error('Condition evaluation error:', error);
      return false;
    }
  }

  // 表达式求值
  evaluateExpression(expr) {
    const interpolated = this.interpolate({ text: expr }).text;
    try {
      const func = new Function('gameState', `return ${interpolated}`);
      return func(this.state.globalState);
    } catch (error) {
      console.error('Expression evaluation error:', error);
      return expr;
    }
  }

  // 字符串插值（${gameState.xxx}）
  interpolate(content) {
    if (typeof content === 'string') {
      return content.replace(/\$\{([^}]+)\}/g, (match, expr) => {
        return this.evaluateExpression(expr);
      });
    } else if (typeof content === 'object') {
      const result = {};
      for (const [key, value] of Object.entries(content)) {
        if (typeof value === 'string') {
          result[key] = this.interpolate(value);
        } else if (typeof value === 'object') {
          result[key] = this.interpolate(value);
        } else {
          result[key] = value;
        }
      }
      return result;
    }
    return content;
  }

  // 处理表单（条件字段、插值）
  processForm(formDef) {
    const processed = JSON.parse(JSON.stringify(formDef));
    
    for (const section of processed.sections) {
      section.fields = section.fields.filter(field => {
        // 处理 showIf 条件
        if (field.showIf) {
          return this.evaluateCondition(field.showIf);
        }
        return true;
      });
      
      // 插值 defaultValue
      for (const field of section.fields) {
        if (field.defaultValue && typeof field.defaultValue === 'string') {
          field.defaultValue = this.interpolate(field.defaultValue);
        }
      }
    }
    
    return processed;
  }

  // 验证表单
  validateForm(formDef, formData) {
    const errors = [];
    
    for (const section of formDef.sections) {
      for (const field of section.fields) {
        const value = formData[field.id];
        
        // 必填检查
        if (field.required && !value) {
          errors.push(`${field.label}是必填项`);
        }
        
        // 自定义验证
        if (field.validation && field.validation.type === 'custom') {
          const isValid = this.executeFunction(
            field.validation.rule,
            { field, value, formData, gameState: this.state.globalState }
          );
          if (!isValid) {
            errors.push(field.validation.message);
          }
        }
      }
    }
    
    // 表单级验证
    if (formDef.validation?.rules) {
      for (const rule of formDef.validation.rules) {
        const isValid = this.executeFunction(
          rule.rule,
          { formData, gameState: this.state.globalState }
        );
        if (!isValid) {
          errors.push(rule.message);
        }
      }
    }
    
    return {
      valid: errors.length === 0,
      errors
    };
  }

  // 注册内置函数
  registerBuiltInFunctions() {
    this.functions = {
      // 车辆容量验证
      validateVehicleCapacity: ({ field, value, formData, gameState }) => {
        const vehicleType = formData.vehicleType;
        const vehicleCount = value;
        const cargoVolume = gameState.cargoInfo?.volume || 0;
        
        if (vehicleType === 'box_truck') {
          const totalCapacity = 40 * vehicleCount;
          return totalCapacity >= cargoVolume;
        }
        
        return true; // 平板车无限制
      },

      // 预算检查
      checkBudget: ({ formData, gameState }) => {
        const totalCost = calculateTotalCost(formData, gameState);
        return totalCost <= gameState.budget;
      },

      // 天气防护检查
      checkWeatherProtection: ({ formData, gameState }) => {
        if (gameState.weather?.rain && 
            formData.vehicleType === 'flatbed' &&
            formData.rainProtection === 'none') {
          return false;
        }
        return true;
      },

      // 计算表单得分
      calculateFormScore: ({ form, gameState }) => {
        let score = 60; // 基准分
        
        // 最优方案
        if (form.vehicleType === 'flatbed' && 
            form.rainProtection === 'heavy_duty') {
          score = 95;
        } else if (form.vehicleType === 'box_truck') {
          score = 85;
        }
        
        // 成本效率加分
        const totalCost = calculateTotalCost(form, gameState);
        if (totalCost < gameState.budget * 0.7) {
          score += 5;
        }
        
        return score;
      }
    };
  }

  // 执行自定义函数
  executeFunction(funcName, context) {
    const func = this.functions[funcName];
    if (!func) {
      console.error(`Function not found: ${funcName}`);
      return false;
    }
    return func(context);
  }

  // 计算最终评分
  async calculateScore() {
    const scoringRules = this.scene.scoringRules;
    const scorer = new UniversalScorer(scoringRules, this.state);
    return scorer.calculate();
  }
}

// 辅助函数
function calculateTotalCost(formData, gameState) {
  let cost = 0;
  
  // 车辆费用
  const vehiclePrice = formData.vehicleType === 'box_truck' ? 1200 : 800;
  cost += vehiclePrice * formData.vehicleCount;
  
  // 防雨措施费用
  if (formData.vehicleType === 'flatbed') {
    if (formData.rainProtection === 'heavy_duty') {
      cost += 150 * formData.vehicleCount;
    } else if (formData.rainProtection === 'plastic_wrap') {
      cost += 400;
    }
  }
  
  // 人工费用（厢式货车）
  if (formData.vehicleType === 'box_truck') {
    cost += 320; // 简化计算
  }
  
  return cost;
}
```

```vue
<template>
  <div class="universal-form">
    <h3>{{ form.meta?.title }}</h3>
    <p v-if="form.content?.instruction">{{ form.content.instruction }}</p>

    <div class="form-sections">

      </div>

      <button @click="handleSubmit">{{ form.form.submitButton || '提交' }}</button>
    </div>

    <div v-if="errors.length > 0" class="form-errors">
      <div v-for="error in errors" :key="error" class="error-item">

      </div>
    </div>

<script>
import TextField from './fields/TextField.vue';
import SelectField from './fields/SelectField.vue';
import NumberField from './fields/NumberField.vue';
import TimeField from './fields/TimeField.vue';

  name: 'UniversalForm',
  components: {
    TextField,
    SelectField,
    NumberField,
    TimeField,
    CalculatedField
  },
  props: {
    form: Object,
    gameState: Object
  },
  data() {
    return {
      formData: {},
      errors: []
    };
  },
  methods: {
    getFieldComponent(type) {
      const map = {
        'text': 'TextField',
        'select': 'SelectField',
        'number': 'NumberField',
        'time': 'TimeField',
        'calculated': 'CalculatedField'
      };
      return map[type] || 'TextField';
    },

    getActiveHints(field) {
      if (!field.hints) return [];
      
      return field.hints.filter(hint => {
        if (!hint.condition) return true;
        return this.evaluateCondition(hint.condition);
      });
    },

    evaluateCondition(condition) {
      // 使用引擎的条件评估逻辑
      return this.$engine.evaluateCondition(condition);
    },

    handleFieldChange(field) {
      if (field.onChange) {
        this.$emit('field-change', {
          fieldId: field.id,
          value: this.formData[field.id],
          onChange: field.onChange
        });
      }
    },

    async handleSubmit() {
      this.$emit('submit', this.formData);
    }
  }
};
</script>
```

## 八、总结

### 核心设计原则

1. **内容与代码分离**
   - 内容是数据（JSON/YAML）
   - 代码是引擎（通用逻辑）

2. **配置驱动**
   - 所有场景特性都可配置
   - 不写死在代码里

3. **原子化节点**
   - 节点类型标准化
   - 可任意组合

4. **表达式系统**
   - 支持条件判断
   - 支持状态插值
   - 支持自定义函数

### 可扩展性

**添加新节点类型：**
```javascript
// 只需要：

nodeHandlers['new_type'] = async (node) => { /* ... */ };

}
```

**添加新的工具类型（如拖拽排序）：**
只需要一个新的Vue组件，引擎自动支持。

### 最佳实践

1. **场景设计**
   - 先画决策树图
   - 再转换为JSON
